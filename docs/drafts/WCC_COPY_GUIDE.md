## 1. 語り手ペルソナ（最重要）

### 定義

> **WCC は、ふたりの擬似親友として、ふたりに語りかける。**

WCC というサービス自体が「結婚式当日にそこにいる親友のような存在」として機能することを、コピーで体現する。

これは「文体と感情温度の設定」であり、現実の関係性の描写ではない。
WCC は初対面のサービスである事実は変わらない。

### 重要な区別

- ❌ **誤った理解**: 親友がサービスを紹介している
- ⭕ **正しい理解**: サービス自体が擬似親友として喋っている

つまり LP のコピーは「擬似親友である WCC が、ふたりに語りかけている」テキスト。

### 想定読者の性別

主な想定読者は **花嫁** であるため、語り手も同性として設計する（ジェンダーをコピーから排除する目的）。
ただし「同性の親友」という設定はあくまで温度感の指針であり、コピー上で「私は女性です」のような明示はしない。

### 語り手の感情と性質

- ふたりの関係と愛を、心から祝福している
- 感情が溢れる・涙もろい
- 「最高に幸せだから！」と興奮気味に伝える温度感
- 押し売りしない。でも「これ絶対やったほうがいい」という確信がある
- 業界の専門家ではなく、ふたりの幸せを願う人間として喋る

### 禁止（ペルソナ起因）

以下の表現は「過去の関係性の嘘」になるため完全禁止:

- 「ずっと」「いつも」「見てきた」「知っている」
- 「あなたのことを思うと」（個人的な関係を示唆）
- 「これまでの」「これからも」（継続的な関係の示唆）

WCC は当日初めてふたりに会う擬似親友。過去の記憶や関係性は持たない。

## 2. 感情温度のルール

### 基本原則

**前提**: 読者（花嫁・婚約カップル）は人生で最も幸せな時期にいる。
その温度感に合わせた、祝福に満ちたコピーでなければ響かない。

### 感情温度のサンプル

このガイドが目指す感情温度の基準として、以下のサンプルを参照する:

> 「次の日見てみて、最高に幸せだから！」
> 「翌朝届けるから、ふたりで見て！」

この温度感が、すべての本文・キャッチコピーで再現されるべき水準。

### ルール

#### 1. 否定形を完全排除する

- ❌ 「〜ではありません」「〜しなくてもいい」「〜は必要ありません」
- ❌ 「〜ではなく、〜」（比較否定）
- ❌ 「〜じゃなくて」（口語の否定形）
- ⭕ 「〜です」「〜があります」「〜できます」

理由: 否定形は感情温度を下げる。祝福の文脈に合わない。
**比較優位（〇〇 vs △△）も否定形と同じ扱いで排除する**。

#### 2. 比較優位を使わない

- ❌ 「写真は瞬間を、動画はその日の流れを残します」（比較）
- ❌ 「普通のビデオとは違う」（他者を下げる）
- ⭕ 「ふたりの目線をそのまま残す」（自分の在り方だけを語る）

#### 3. 感情を出していい・むしろ出すべき

- 淡々とした説明調は禁止
- 感嘆符「！」を本文で**多めに**使う
- フィラー「ほんとに」「絶対」「だから」「全然」を積極的に使う
- 「〜から！」「〜よ！」「〜だから！」のような口語的感情表現を許容
- ただし「感動」「奇跡」「最高の」は引き続き禁句（後述）

#### 4. 祝福を前提にする

- 読者が「幸せな状況にいる」ことを前提に書く
- 「もし〜なら」「〜に悩んでいる方へ」のような問題提起型の書き出しは使わない
- 状況の悲観・懸念を示す表現を使わない

## 3. 二人称のルール

### 原則

擬似親友が呼ぶなら、呼び方は **「ふたり」** が中心。

### 詳細規定

| 用途 | 表記 | 理由 |
|---|---|---|
| ヒーロー・キャッチコピー・本文 | **ふたり** | 親友としての距離感、敬語を超えた温度 |
| 業務文・契約・フォーマル | **お二人** | 業務上の敬意 |
| 「あなた」 | **禁止** | 個人への冷たい語りかけになる |
| 「おふたり」 | **避ける** | 中途半端、ペルソナと合わない |

v1 では「ふたり / おふたり / お二人」の 3 種使い分けにしていたが、v2 ではペルソナ強化により「ふたり」を主とする。
業務文（Pricing 詳細・契約・FAQ など）でのみ「お二人」を許容。

### 具体例

- ヒーロー H1: 「翌朝、ふたりで観る、昨日のすべて」✅
- 本文: 「ふたりのそばにいる」✅
- Bespoke 業務文: 「お二人専用のプランをお見積もりします」✅
- Do I need: 「あなたに向いています」❌ → 「ふたりに合うかも！」✅

## 4. 語彙レベルのルール

### 基準: 頭のいい高校 2 年生

実際の婚礼年齢（20 代後半〜30 代）よりも下の語彙を意識する。
理由: あまねく価値観や知性の方に理解してもらうため。伝わることを最優先する。

### 漢字を開く

難しい漢字は積極的にひらがなに開く。

| ❌ 漢字 | ⭕ ひらがな |
|---|---|
| 観る | 見る |
| 上げる（SNS に〜） | あげる |
| 仕立てる | つくる / する |
| 拾う | そのまま使う（漢字でも読める） |
| 観返す | 見返す |
| 紡ぐ | 比喩で残す（用法による） |

### 平易な単語に置き換える

| ❌ 難しい単語 | ⭕ 平易な単語 |
|---|---|
| 補完的 | （使わず削除） |
| 内訳 | 中身 |
| 目安 | だいたい / めやす |
| 興奮 | 気持ち |
| 余韻（本文では） | 気持ち / あの感じ |
| 検討 | 考える |
| 案内する | 教える |
| 共有する | 教える / 送る |

### 専門用語の扱い

業界用語は**最小限**に限定:

許容: ウェディング / カメラマン / ムービー / SNS / iPhone / 9:16 縦動画
禁止: クリエイト / クリエイター / コンテンツクリエーション / ストーリーテリング

## 5. 文体トーンのルール

### 基本スタンス: 感情温度の高い親友の語り

ペルソナから逆算した文体:
親友は押し売りしない。でも「これ絶対いいよ」という確信がある。
その確信を、感情温度を保ちながら自然に伝える。

### 許容する表現パターン

| パターン | 例 | 機能 |
|---|---|---|
| 問いかけ | 「翌朝、ふたりで見れる動画って、手元にある?」 | 読者の自分事化 |
| 状況描写 | 「翌朝、コーヒー淹れて、ふたりで見る」 | 体験の先取り |
| 感情的な短文 | 「絶対、泣くから！」「最高に幸せだから！」 | 温度の頂点 |
| 控えめな機能描写 | 「全部そこにいて、全部拾う」 | 在り方の提示 |
| 親友の呼びかけ | 「見てみて！」「話そう！」「チェックして！」 | 距離の近さ |

### 禁止する表現パターン

| パターン | 例 | 理由 |
|---|---|---|
| 否定形 | 「〜ではない」「〜じゃなくて」 | 感情温度を下げる |
| 比較優位 | 「普通の〜とは違い」 | 他者を否定する |
| 営業定型句 | 「お気軽に」「ご不明な点は」「何なりと」 | 業務的・冷たい |
| 命令形（業務的） | 「ご検討ください」「お申し込みください」 | 押し売り感 |
| 問題提起型 | 「〜に悩んでいませんか?」「〜が心配な方へ」 | 祝福の文脈と合わない |
| 大げさな感情表現 | 「感動」「奇跡」「最高の瞬間」「永遠に」 | BRAND v2 禁句、嘘っぽい |
| 過去関係性の示唆 | 「ずっと」「見てきた」 | ペルソナの嘘になる |
| 淡々とした説明 | 「〜は〜です」の連続 | 親友の話し方ではない |

### 文体の口語化

- 「〜です・〜ます」を基本としつつ、感情の頂点では「〜から！」「〜よ！」などの口語的語尾を許容
- 「〜である」「〜だ」調は禁止
- 体言止めは見出しのみ、本文では避ける

## 6. 比喩のルール

### 使いどころ

ペルソナから逆算した比喩は **口語に近い、日常的な情景描写**。難解な詩的比喩ではない。

### セクション別使用方針

| セクション | 比喩の使用 | 理由 |
|---|---|---|
| ヒーロー H1・サブ | **積極的に使う** | 詩的・感情的な掴み |
| OUR WORK（Highlights） | 控えめ | 動画が主役 |
| What is | 情景描写は OK、比喩は控えめ | 業界解説の客観性を保ちつつ温度は出す |
| Do I need | 控えめ（読者の状況描写は OK） | 判断材料の提示 |
| Pricing | 使わない | 業務情報の正確性 |
| service-flow / FAQ | 使わない | 手順・Q&A の明快さ |
| フッター CTA | **積極的に使う** | 締めの余韻 |

### 推奨情景描写ストック

- 「翌朝、コーヒーを淹れて」
- 「ふたりで見る」
- 「あの日を振り返る」
- 「気持ちが冷めないうちに」
- 「家族に、ゲストに、すぐ送れる」
- 「ふたりだけの一本」

### 禁止する比喩

- 「輝かしい」「永遠に光り続ける」「宝物のような」（誇張・大げさ）
- 「奇跡の瞬間」「運命の出会い」（断定・BRAND v2 禁句）
- 業界的な比喩（「映画のような」「雑誌のような」）→ WCC の独自性が消える

## 7. 文章長のルール

### 字数目安

| 用途 | 字数目安 | 段落数 |
|---|---|---|
| ヒーロー H1 | 15 字以内 | 1 |
| ヒーロー サブコピー | 30〜50 字 | 1〜2 文 |
| セクション H2 | 8〜15 字 | 1 |
| セクション本文（各段落） | 60〜90 字 | 1 段落あたり |
| セクション本文（段落数） | 最大 2 段落 | - |
| Pricing 内訳箇条書き | 10〜25 字 / 項目 | - |
| FAQ 質問 | 15〜25 字 | 1 |
| FAQ 回答 | 50〜100 字 | 1〜2 文 |
| service-flow ステップ | 30〜60 字 | 1 |
| フッター CTA H2 | 8〜15 字 | 1 |
| フッター CTA 本文 | 20〜40 字 | 1〜2 文 |

### 文章リズムのルール

親友の話し方は、長い文を一本で喋らない。**短い文を重ねる**。

- 1 文 30 字以内を目安に、本文段落内でリズムを作る
- 体言止めは見出しのみ
- 〜です / 〜ます基本（感情の頂点では「〜から！」「〜よ！」許容）
- 1 文に読点「、」は最大 3 個まで

### 具体例

❌ 悪い例（長すぎ・一文に情報詰め込みすぎ・温度ゼロ）:
「すでに写真家や本編ムービーカメラマンを手配していても、当日の自然な表情やゲストとの笑い合いなど、プロの機材では難しいインフォーマルな瞬間を iPhone で記録し、翌日中に SNS で使える縦動画として納品するサービスです。」

⭕ 良い例（短文を重ねる・感情が出る・温度高い）:
「翌朝、ふたりで見れる動画って、手元にある? 当日、ふたりのそばにいる。笑ったとき、泣いたとき、全部そこにいて、全部拾う！次の日見てみて、最高に幸せだから！」

## 8. 句読点ルール

### 句点「。」

- **見出し（H1 / H2）**: なし
- **本文・説明文・案内文**: あり（文末に必ず）
- **キャッチコピー・詩的ステートメント**: なし

### 読点「、」

- 文法的な区切りに使う（息継ぎのための多用は避ける）
- 見出しでは詩的リズムのために使ってよい（例: 「翌朝、ふたりで観る、昨日のすべて」）
- 1 文に最大 3 個まで

### 感嘆符「！」

**v1 から方針変更**: 感嘆符を **多めに使う**。

- 見出し・キャッチコピー: 使わない（詩的潔さを保つ）
- 本文: **多めに使う**（1 段落に 1〜3 個目安）
- フッター CTA・呼びかけ: 積極的に使う
- 親友の話し方として自然なリズムで配置

### その他の句読点

| 記号 | ルール |
|---|---|
| 中黒「・」 | 並列表記に使う（例: 「家族に、ゲストに」のほうが温度が出るので、並列は読点で表現するのが第一推奨） |
| 疑問符 | 半角「?」を使う |
| 括弧（） | 説明補足に使う（全角） |
| 「」 | 引用・セリフに使う |

## 9. 禁句リスト（BRAND v2 から継承・拡張）

### BRAND v2 からの継承

- 感動の（断定）/ 感激 / 涙が止まらない
- 最高の / 奇跡の / 永遠に / 永遠の
- プラットフォーム / AI / お客様
- VIBES / bestie 直訳

### 本ガイドで追加（感情温度起因）

**業務的な定型句**:
- 「ご不明な点は」「何なりと」「お気軽に」「ご検討ください」
- 「ご案内します」「お渡しします」「ご一報ください」

**問題提起型**:
- 「〜に悩んでいませんか?」「〜が心配な方へ」「〜にお困りの方」

**比較優位**:
- 「普通の〜とは違い」「〜だけでは」「〜では足りない」

**過去関係性の示唆**:
- 「ずっと」「いつも見てきた」「知っている」「これまでの」

**否定形（全面禁止）**:
- 「〜ではありません」「〜しなくてもいい」「〜は必要ありません」
- 「〜できない」「〜がない」（機能説明でも否定形を使わない）
- 「〜ではなく、〜」「〜じゃなくて」（比較否定）
