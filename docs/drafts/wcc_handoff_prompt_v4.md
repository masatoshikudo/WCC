## 重要な設計原則（継承）

- **完了の定義**: 「マージ済み + 動作確認済み」で統一
- **ドキュメント運用**: 削除ではなく完了マークで判断の歴史を残す
- **議論したい論点**: 「忘れない仕組み」として記録、実顧客フィードバック後に再検討
- **Step 分割**: 一気にやらず段階を区切ることでデバッグ可能性を担保
- **Pre-Implementation Research Pattern**: 実装前に必ず調査、案A/B/Cで判断材料提示
- **ベンチマーク使用時**: 機械的コピーを避け、自プロジェクト特性で翻訳
- **ビジュアルとコピーの分離**: 海外参考はビジュアル要素のみトレース、コピーは日本市場向け独自表現
- **PR 分割の運用ルール**: コード修正とドキュメント追加は原則として別 PR に分割（CLAUDE.md に記載済み）
- **事業実態と整合する約束原則**: 具体数値（時刻・本数）を確定的に書かない、抽象表現を優先

## 確定済みコピー方針

### 中心軸（v3）

- **「明日の2人」**: ヒーロー H1・フッター CTA H2 で使用
- **「次の日の朝」**: 本文・口語的表現
- **24 時間以内**: 業務文での確定的約束
- **「最高に幸せだから！」**: 感情温度の頂点表現

### 語り手ペルソナ

WCC は花嫁の同性の擬似親友として喋る。
過去の関係性は持たない（「ずっと」「いつも」「見てきた」は禁句）。
感情温度は高く、否定形・比較優位は完全排除。

### 二人称使い分け（v3）

| 用途 | 表記 |
|---|---|
| 詩的キャッチコピー・SNS ライク | **2人** |
| 本文・解説 | **ふたり** |
| 業務文・契約 | **お二人** |
| 「あなた」 | **禁止** |

### 禁句リスト

- 感動 / 永遠 / 最高の / 奇跡の（断定）
- 翌朝（事業実態との齟齬で v3 廃止）
- 「ひとつ届ける」（本数固定で Extras 拡張時に矛盾）
- お気軽に / ご検討ください / ご案内します / お渡しします
- ずっと / いつも / 見てきた / これまで
- 否定形（〜ではない / 〜じゃなくて）
- 比較優位（〜だけでは / 普通の〜とは違い）

### 推奨語

- 明日の2人 / 次の日の朝 / 朝起きたら
- ふたり / 2人 / お二人（用途別）
- 余韻 / 軽やかに / そっと
- 24 時間以内
- 家族に、ゲストに
- 最高に幸せだから！ / 絶対、いい！
