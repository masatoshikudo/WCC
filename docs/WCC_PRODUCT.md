## 1. サービスの全体像

### 1.1 提供価値

WCC は、結婚式当日の空気を 24 時間以内に **明日の 2 人** へ届ける縦動画サービス。

- iPhone または DJI Osmo Pocket による親密な距離での撮影
- 9:16 縦動画 + 全素材納品
- 翌日 SNS で家族・ゲストへすぐシェア可能

### 1.2 想定読者

- 主に花嫁が情報を取得・判断する想定
- 婚約〜結婚式の数ヶ月前のカップル
- プロのカメラマン・ビデオグラファーは別途契約済みの想定（補完軸）

### 1.3 差別化軸

| 軸 | WCC | 一般的なフォト・ビデオ |
|---|---|---|
| 納品速度 | 24 時間以内 | 1〜数ヶ月後 |
| 距離感 | 親友のような近さ | プロの第三者視点 |
| 機材 | iPhone / DJI Osmo Pocket | 一眼レフ / シネマカメラ |
| 用途 | SNS 即シェア | 記念保存 |
| 価格帯 | 176,000 円〜 | 数十万〜数百万 |

## 2. スタンダードプラン

### 2.1 価格

**176,000 円（税込）**

- 税抜 160,000 円 + 消費税 16,000 円
- BtoC 表示原則に従い、税込価格を一次表記とする

### 2.2 含まれるもの

| 項目 | 内容 |
|---|---|
| 撮影スタッフ | WCC スタッフ 1 名 |
| 機材 | iPhone または DJI Osmo Pocket |
| 撮影時間 | **4 時間連続**（後述 2.3 参照） |
| 納品 | 撮影終了から 24 時間以内 |
| 編集済み動画 | 9:16 縦動画 2 本 |
| 素材納品 | 未編集の全素材 |
| 事前打ち合わせ | ご決済後の ZOOM ミーティング |
| サポート | ご決済後の公式 LINE 対応 |

### 2.3 撮影時間の定義（重要）

**「4 時間連続」の意味**:

撮影開始時刻から **ストップせず連続** で 4 時間を計測する。
途中の空き時間（移動・待機・お色直し等）も「4 時間」に含まれる。

```
撮影開始 13:00 ─── (4時間経過) ─── 撮影終了 17:00
            ↑ この間の待機・移動も時間内に含む
```

**この定義の理由**:
- 1 日 3 組撮影可能な体制（4 時間 × 3 = 12 時間 + 移動）
- 新郎新婦の「時間を細切れに使う」希望を防ぐ
- 撮影者の負担が予測可能
- 経過時間管理が運用上シンプル

**4 時間で撮影可能な範囲の目安**:
- 挙式 + 披露宴の主要部分（標準的なケース）
- または披露宴 + 二次会の前半
- または挙式 + 披露宴の主要シーン + 集合写真

二次会まで含めるケース、または前撮りから含めるケースは Extras（撮影時間延長）で対応。

### 2.4 サービス価値の核

- **シーンを問わない 4 時間**: 挙式・披露宴・二次会のいずれも対象
- **24 時間納品**: 「明日の 2 人」がホテル滞在中・日常への戻り道で観られる
- **SNS 即時シェア**: 家族・ゲストの夕方〜夜の閲覧ピークに間に合う

## 3. Extras（追加オプション）

### 3.1 撮影時間延長

**価格**: +33,000 円 / 1 時間

**用途**:
- 4 時間スタンダードを超える時間が必要な場合

**注意点**:

### 3.2 追加編集動画（9:16 縦動画）

**価格**: +33,000 円 / 1 本

**用途**:
- スタンダードの 2 本を超えて編集動画が欲しい場合

**注意点**:

### 3.3 WCC スタッフ追加

**価格**: +132,000 円 / 1 名

**用途**:
- 2 人体制での撮影

**価格根拠**:

**注意点**:
- 案件全体（時間内）固定料金

### 3.4 機材貸出（DJI Osmo Pocket）

**価格**: +38,500 円 / 1 台

**最大数**: 2 台 / 案件

**用途**:
- 友人代表に DJI Osmo Pocket を貸し出し、友人視点での撮影を依頼
- 例: 新郎側友人 1 名 + 新婦側友人 1 名 = 2 人の友人視点

**価格根拠**:
- DJI Osmo Pocket の市場レンタル相場（7 泊 8 日）: 約 8,000 円
- 編集リソース増加分（友人映像を編集対象に組み込む工数）: 約 28,000 円
- 保険・消耗品分: 約 2,500 円
- 合計: **38,500 円 / 1 台**

**運用設計**:
- 当日スタッフが機材を持参・友人代表に手渡し
- スタッフが当日 5 分程度の口頭説明（撮影してほしいシーンの指示）
- メモリカード容量制限により編集対象量を物理的にコントロール（最小容量を使用）
- 友人映像は編集対象に含める（標準の 2 本に組み込む）

**責任設計**:
| 項目 | 取り決め |
|---|---|
| 機材破損時 | WCC 側で負担 / 保険適用 |
| 撮影内容の権利 | WCC に帰属（契約書で明示） |
| 撮影量のコントロール | メモリカード容量制限で物理的に制御 |

**事前ガイドの提供**: 実績蓄積後（M2 以降）に検討。当面はスタッフの当日口頭説明のみ。

## 5. 業務フロー

### 5.1 全体像

```
1. LP 訪問
2. /book フォーム入力（事前ヒアリング）
3. 送信 → 自動メール送信
4. WCC が内容確認・見積もり作成
5. 見積もりメール送信
6. ご確認後、Stripe 請求書送付
7. ご決済完了
8. 公式 LINE 招待
9. ZOOM 詳細打ち合わせ日程調整
10. ZOOM 詳細打ち合わせ実施
11. 撮影当日
12. 24 時間以内納品
13. 公式 LINE で納品連絡・フォロー
```

### 5.2 v1 からの変更（重要）

**v1（旧フロー）**:
- LP → 問い合わせ → 無料 ZOOM 相談 → 契約 → 決済 → 撮影

**v2（新フロー）**:
- LP → /book フォーム → メール対応 → 見積もり → 請求書 → 決済 → 公式 LINE → ZOOM 詳細打ち合わせ → 撮影

**変更理由**:
- 契約前の無料 ZOOM 相談を廃止し、稼働コストを抑制
- 失注時の稼働を「メール返信時間」に限定
- 信頼形成は契約後に集中投資（公式 LINE + ZOOM 詳細打ち合わせ）

### 5.3 各ステップの詳細

#### Step 1〜3: LP → /book → 送信

- LP の「まず相談する」CTA → `/book` ページへ遷移
- `/book` フォームで事前ヒアリング（以下の項目）
  - 基本情報（新郎・新婦名、メール、電話番号）
  - 挙式日・式場名・所在地
  - 当日の開始時刻
  - 撮影範囲の希望
  - 撮ってほしいシーン
  - 使用予定媒体
  - Extras 希望（撮影時間延長・追加編集動画・スタッフ追加・機材貸出）
- 送信後、自動メールで「次の流れ」を案内

#### Step 4〜5: 内容確認 → 見積もりメール

- WCC が `/book` の入力内容を確認
- Extras 希望に基づき見積もり計算
- 遠方出張費の要否を式場所在地から判定
- メールで見積もりを送信

#### Step 6〜7: 請求書 → 決済

- ご確認後、Stripe Invoice で請求書を送付
- 決済完了で契約成立

#### Step 8〜10: LINE → ZOOM 詳細打ち合わせ

- 公式 LINE への招待リンクを送付
- ZOOM ミーティングの日程を調整
- 詳細な撮影内容・タイムライン・希望シーンを ZOOM で確認

#### Step 11〜13: 撮影 → 納品 → フォロー

- 撮影当日、4 時間連続で撮影
- 撮影終了から 24 時間以内に編集動画 2 本 + 全素材を納品
- 公式 LINE で納品連絡

## 7. v1 → v2 変更履歴と判断記録

### 7.1 撮影時間: 6h → 4h

**変更理由**:
- 1 日 3 組撮影可能な稼働効率を実現
- 6h スタンダードでは 1 日 1〜2 組が限界
- 4h スタンダードなら 1 日 3 組まで可能、延長アップチャージで売上機会を補填

**事業計算**:
- 6h スタンダード: 176,000 × 2 組 = 352,000 円/日
- 4h スタンダード: 176,000 × 3 組 = 528,000 円/日
- 4h + 延長 4h（フル稼働 1 組）: 308,000 円/組

**判断記録**: 2026-05-07 第3回セッション

### 7.2 価格据え置き 176,000 円

**変更理由**:
- 撮影時間は「稼働の指標」であって「サービスの価値」ではない
- WCC の価値は「式当日の空気を 24 時間以内に届ける」体験全体
- 価格を下げると Bespoke（220,000 円〜）との単価バランスが崩れる

**判断記録**: 2026-05-07 第3回セッション

### 7.3 Extras 拡張: スタッフ追加・機材貸出を新設

**追加項目**:
- WCC スタッフ追加: +132,000 円
- 機材貸出（DJI Osmo Pocket）: +38,500 円 / 1 台

**変更理由**:
- 友人代表撮影オプションを WCC の独自性として提供可能に
- ビハインド・ザ・シーン撮影など、複雑な案件への対応
- スタンダードを抑えつつ拡張性を確保

**判断記録**: 2026-05-07 第3回セッション

### 7.4 業務フロー: 無料相談 → メール対応に変更

**変更理由**:
- 契約前の無料 ZOOM 相談を廃止し、稼働コストを抑制
- 失注時の稼働を「メール返信時間」に限定
- 信頼形成は契約後（公式 LINE + ZOOM 詳細打ち合わせ）に集中

**判断記録**: 2026-05-07 第3回セッション

### 7.5 撮影時間定義の明確化（4 時間連続）

**変更理由**:
- 「合計 4 時間（分割可能）」だと運用が複雑化
- 撮影開始から連続 4 時間とすることで、新郎新婦の希望と稼働の物理的制約を整合
- 1 日 3 組稼働の前提条件として必須

**判断記録**: 2026-05-07 第3回セッション

### 7.6 友人代表撮影オプションの責任設計

**確定事項**:
- 機材破損時は WCC 側で負担（または保険適用）
- 撮影内容の権利は WCC に帰属
- 編集量は メモリカード容量制限で物理コントロール
- 友人映像は標準 2 本に組み込む（追加納品しない）
- 当日 5 分の口頭説明のみ（事前ガイドは M2 以降）

**判断記録**: 2026-05-07 第3回セッション

### 7.7 撮影時間延長の計算ルール（スタッフ追加時の +25% 加算）

**確定事項**:
- 1 名追加につき延長料金 +25% 加算
- 計算式: 33,000 円 × (1 + (スタッフ人数 - 1) × 0.25)
- 2 名体制延長 1h: 41,250 円、3 名体制延長 1h: 49,500 円

**変更理由**:
- スタッフ追加（+132,000 円）を「長時間割引価格」と位置付け
- 延長時は補助単価で加算する設計で、顧客のお得感とサービス維持を両立
- 計算ルールが明快（25% 加算 1 行で説明可能）

**判断記録**: 2026-05-07 第3回セッション

## 9. 留意事項とリスク

### 9.1 4 時間連続での運用リスク

- 4 時間で挙式 + 披露宴をカバーできない大規模披露宴の場合、延長必須
- 新郎新婦が「4 時間で何ができるか」を事前に正確に理解する必要がある
- → `/book` フォームで具体的な希望シーンを書いてもらうことで対応

### 9.2 友人代表撮影オプションのリスク

- 友人代表が撮影に消極的な場合、想定外の素材が得られない
- メモリカード容量制限を正しく運用しないと、編集工数が爆発する
- → 当日のスタッフ説明と、事後の編集ポリシーで対応

### 9.3 業務フロー変更による顧客離脱リスク

- 「無料相談がない」ことに不安を感じる新郎新婦が一定数存在する可能性
- → LP の情報密度（特に `/pricing` ページ）を高く保つ
- → 自動メールで「次の流れ」を明確に示す
- → 必要に応じて、メール返信を「実質的な相談」として機能させる

### 9.4 スタッフ追加時の延長料金計算（確定済み）

スタッフ人数に応じて、延長料金が加算される。

**基本式**:

```
延長料金 / 1 時間 = 33,000 円 × (1 + (スタッフ人数 - 1) × 0.25)
```

**具体例**:

| スタッフ人数 | 延長料金 / 1 時間 | 補助スタッフ加算分 |
|---|---|---|
| 1 名体制 | 33,000 円 | - |
| 2 名体制 | 41,250 円 | +8,250 円 |
| 3 名体制 | 49,500 円 | +16,500 円 |

**料金根拠**:

- メインスタッフの延長単価: 33,000 円 / 1 時間
- 補助スタッフ追加分: 8,250 円 / 1 時間 / 1 名（メイン単価の 25%）
- スタッフ追加（+132,000 円 / 1 名）は時間内固定の長時間割引価格として位置付け、延長時は補助単価で加算
